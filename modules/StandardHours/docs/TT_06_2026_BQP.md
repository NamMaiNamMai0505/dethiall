## 7. ⚠️ Điều 17 — Vượt định mức theo **bộ môn** (CHƯA TRIỂN KHAI)

### 7.1 Nội dung TT

1. **Số giờ chuẩn vượt định mức được tính chung cho bộ môn** (hoặc khoa có **01** bộ môn).  
2. Tổng vượt = Tổng giờ thực hiện − Tổng giờ phải thực hiện theo định mức.  
3. Phân bổ vượt cho từng nhà giáo: **dân chủ, công khai, công bằng**.  
4–8. Không trùng thù lao nguồn khác; mời giảng ngoài; bồi dưỡng vượt DM…

### 7.2 Web (đã triển khai)

| Hạng mục | Hiện trạng |
|----------|------------|
| Tính kết quả cá nhân | `YearlyResult` + giảm trừ Đ.11.3 |
| Entity **Bộ môn** | `academic_departments` (thuộc `unit_id` = khoa) |
| Gán GV | `instructors.department_id` — **chỉ** cho vượt DM; filter khác vẫn theo khoa |
| Pool vượt | `department_overtime_pools` = Σ done − Σ must |
| Phân bổ | `department_overtime_allocations` + khóa pool |
| UI | Hub → Bộ môn / Vượt DM bộ môn / Giảm trừ Đ.11.3 |

### 7.3 Phương án triển khai hoàn chỉnh (khi chốt làm)

#### A. Mô hình dữ liệu

```
units (khoa)
  └── departments / bo_mon  (bộ môn thuộc khoa)
        └── instructors.department_id  (GV thuộc BM)
        └── (tuỳ chọn) subjects.department_id
```

- Khoa chỉ **1** BM: cho phép `units.single_department = true` → pool = cấp khoa.  
- Migration: `departments`, `instructors.department_id` (nullable).

#### B. Tính pool vượt (năm học Y, bộ môn D)

```
pool_must   = Σ (định_mức_GC_i × ratio_position_i)   cho mọi GV ∈ D còn hiệu lực năm Y
pool_done   = Σ giờ_chuẩn_thực_hiện_i                 (dạy + quy đổi CM theo rule hiện tại)
pool_excess = max(0, pool_done − pool_must)
```

- “Giờ phải thực hiện” = định mức sau % chức vụ (Đ.12), đã trừ nghỉ (khi có).  
- Không cộng trùng nếu đã tính vượt cá nhân + pool (chọn **một** nguồn chi trả — Đ.17.4).

#### C. Phân bổ (UI + workflow)

1. **Admin khoa / Trưởng BM** mở màn:  
   `StandardHours → Vượt định mức bộ môn → chọn năm + BM`.  
2. Hệ thống hiện bảng:  
   - Tổng pool vượt  
   - Gợi ý chia đều / theo tỷ lệ giờ thực hiện / theo đề xuất Trưởng BM  
3. **Chốt phân bổ** (dân chủ): form nhập giờ vượt gán từng GV + ghi chú biên bản họp;  
   `department_overtime_allocations` (year, department_id, instructor_id, allocated_hours, note, approved_by, locked_at).  
4. Báo cáo / export PDF “Công khai phân bổ vượt DM”.  
5. Khóa năm → không sửa allocation.

#### D. Liên hệ module hiện có

| Module | Việc |
|--------|------|
| `CalculationService` | Thêm `computeDepartmentPool($year, $departmentId)` |
| `YearlyResult` | Cột `department_allocated_overtime` (optional) hoặc bảng riêng |
| `Position` / norm | Giữ nguyên % |
| RBAC | `standard-hours.department-overtime` (khoa + super-admin) |
| Unit | Map K{n} → departments |

#### E. Không làm trong phase 1

- Tự động chuyển NCKH ↔ GC (Điều 14 đoạn 2) — cần quyết định Hiệu trưởng từng case.  
- Bồi dưỡng tiền vượt DM (ngoài phạm vi phần mềm lịch/giờ).  
- Mầm non / phổ thông.

#### F. Thứ tự PR gợi ý

1. Entity Bộ môn + gán GV  
2. Report pool vượt (read-only)  
3. Workflow phân bổ + khóa  
4. Export công khai
